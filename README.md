# InstantWorldMirror

Explore or build in a separate mirror world, with player-state restoration and configurable item-transfer rules.

[Download: CurseForge](https://www.curseforge.com/minecraft/mc-mods/instantworldmirror) · [Modrinth](https://modrinth.com/mod/instant-world-mirror) · [Full guide](https://crabmods.com/mods/mirror) · [Trailer](https://www.youtube.com/watch?v=AMWi2Ea9uMI) · [中文](docs/readme/chn/README.md)

## Choose a mirror

| Mirror | Purpose |
| --- | --- |
| World Reflection | A temporary copy of the configured nearby area |
| Heaven | A Creative sandbox that saves your original player state |
| First Dream | Fresh terrain generated from the current world's seed |
| Stranded | Capture named slices and reopen compatible snapshots from another save |

Permanence supports saved mirror worlds. Renewal and Superflat add options for First Dream and Heaven. Availability, access, mob spawning and item transfer depend on the build and server settings.

## Install and start

Use matching builds on the server and clients. Maintained lanes: Forge 1.20.1 / Java 17 and NeoForge 1.21.1 / Java 21.

Right-click a solid block with a World Reflection, Heaven or First Dream mirror, wait for the portal to finish, then enter. Use `/iwm return` to leave. Stranded first captures a named slice; its menu opens saved slices.

# InstantWorldMirror

在独立的镜像世界中探索或建造，提供玩家状态恢复，以及可配置的物品带出规则。

[CurseForge 下载](https://www.curseforge.com/minecraft/mc-mods/instantworldmirror) · [Modrinth](https://modrinth.com/mod/instant-world-mirror) · [完整指南](https://crabmods.com/mods/mirror) · [预告片](https://www.youtube.com/watch?v=AMWi2Ea9uMI) · [English](../../../README.md)

| 镜子 | 用途 |
| --- | --- |
| 映界之镜 | 复制配置范围内的周边区域，供临时探索和测试 |
| 天堂之镜 | 保存原有玩家状态，进入创造沙盒 |
| 初梦之镜 | 按当前世界种子重新生成地形 |
| 搁浅之镜 | 捕获命名切片，在其他存档中打开兼容快照 |

永久附魔用于保存镜像，复苏和超平坦为初梦、天堂增加选项。能否使用、生成生物或带出物品，取决于具体版本与服务器设置。

服务端与客户端均需匹配版本。当前维护 Forge 1.20.1 / Java 17、NeoForge 1.21.1 / Java 21。前三种镜子右键实体方块，待传送门就绪后进入；用 `/iwm return` 返回。搁浅之镜先捕获命名切片，再从菜单打开。
